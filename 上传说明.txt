二、仓库创建与推送
------------------

2. 用网页上传全部文件（Upload files），或已本地 git 仓库直接 push：
   git remote add origin https://github.com/jeantechno/jean-tomato.git
   git push -u origin main
   （本地仓库已初始化并 commit 好：C:\Users\technology\Doubao\chats\2026-09-26\new-chat-4\jean-tomato-官网）

三、开启 GitHub Pages（官网地址）
--------------------------------
仓库 Settings → Pages → Source 选 "Deploy from a branch" → Branch 选 main / root → Save。
约 1 分钟后官网生效：https://jeantechno.github.io/jean-tomato/
