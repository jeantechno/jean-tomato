技术架构

原生 C# 壳 + WebView2 前端 + Rust 下载内核，三层各司其职。

1

桌面壳

C# WinForms 无边框窗口，DWM 丙烯酸模糊、圆角、八向缩放，自动托管内核进程，关闭即回收。

2

WebView2 前端

HTML / CSS / JS 渲染液态玻璃 UI，经本地同源代理访问内核 API，无需浏览器。

3

Rust 内核

开源 zhongbai2333/Tomato-Novel-Downloader（v2.4.15）--server 模式，提供全部下载能力。
